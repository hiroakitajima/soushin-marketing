# コーポレートサイト改善計画

対象: https://soushin-lab.co.jp  
最終更新: 2026-06-25

---

## 現状の課題

### 🔴 致命的な不足
**実績・事例ページがない**
サービス一覧はあるが「何を作ったか・どんな課題を解決したか」が見えない。初訪問の企業担当者が発注判断をする材料がない状態。

### 🟠 信頼性まわり
- 実績件数・支援社数などの数字がどこにもない（実績は100件近くあるはず）
- 「大手〜スタートアップまで幅広く」と書いてあるが証拠がない
- ニュースの最新が「年末年始休業のお知らせ」で止まっている

### 🟡 ELG・マーケティング文脈
- パートナープログラムへの導線がゼロ
- KASOUへの誘導がサービス一覧の中に埋もれている
- CTAが「開発の相談」「採用」の2つのみ（パートナー向けがない）

### 🟡 メッセージの不明瞭さ
- 「アイデアからイノベーションへ」はビジョンとしてはいいが、誰のどんな課題を解決するのかが一目でわからない

---

## 改善アクション（優先順位順）

### 1. 実績・事例ページの作成（最優先）

**進め方**
1. まずトップページに「支援実績 90件以上」などの数字だけ先に出す（許可不要・すぐできる）
2. クライアントへ掲載許可の打診
   - 優先順位：知名度がある / 成果が数字で出ている / 関係性が良好で断られにくい順
3. 許可が取れない場合は匿名形式で掲載

**掲載フォーマット案**
```
業種：〇〇業
規模：スタートアップ / 中小企業 / 大手
課題：〜ができなかった / 〜に困っていた
解決策：〜を開発・構築した
結果：〜が〇〇%改善 / 〜を実現
```

**掲載件数**：全件不要。厳選10〜15件を深く見せる方が効果的。

### 2. パートナープログラムへの導線追加
- ヘッダーまたはCTAセクションに「パートナー募集」を追加
- ELGパートナーページ（またはKASOUのパートナー登録ページ）へリンク

### 3. KASOUへの誘導強化
- 現状：サービス一覧の「運営メディア」として埋もれている
- 改善：トップページに独立したセクションとして配置、またはヘッダーにリンク追加

### 4. ニュース・コンテンツの定期更新
- 現状：最新が年末年始休業のお知らせ
- 改善：月1本以上の更新体制（実績追加・ブログ・プレスリリースなど）

### 5. CTAの拡充
現状の2種類 → 3種類に

| CTA | ターゲット |
|-----|-----------|
| 開発のご相談 | クライアント（既存） |
| パートナー登録 | デザイナー・フロントエンジニア（新規） |
| 採用エントリー | 求職者（既存） |
