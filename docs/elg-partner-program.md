# ELGパートナープログラム

> 「創新ラボがメーカー、KASOUのデザイナー・フロントエンジニアがパートナーとなるエコシステム」

## 概要

ELG（Ecosystem-Led Growth）の考え方を適用し、KASOUのユーザーコミュニティを活用したパートナープログラム。有形商品のメーカー×代理店モデルをIT開発サービスに置き換えた構造。

| レイヤー | 担当 | 役割 |
|----------|------|------|
| メーカー | 創新ラボ | バックエンド・フルスタック開発 |
| パートナー | KASOUパートナー | デザイナー・フロントエンジニアが案件獲得・提案 |
| エンドユーザー | クライアント企業 | 中小企業・スタートアップ等 |

## パートナータイプ

| タイプ | 役割分担 | 報酬モデル |
|--------|----------|------------|
| 紹介型 | パートナーは紹介のみ。制作は創新ラボが全対応 | 紹介フィー（成約額の○%） |
| 協業型 | パートナーがデザイン・フロント担当、創新ラボがバックエンド・PM担当 | 売上按分（割合を事前決定） |
| 制作型（将来） | パートナーが全制作、創新ラボはPMのみ | PM費用 + マネジメントフィー |

## パートナーの参加動機（価値提案）

「機会損失の解消」が核心。

| Before（現状） | After（創新ラボと組むと） |
|----------------|--------------------------|
| 大きな案件が来ても断る | バックエンドを任せて受注できる |
| フロントしか受けられず単価が低い | フルスタック案件の上流を押さえて単価が上がる |
| 技術的な提案が限定的 | 創新ラボの技術力を使った提案ができる |

## 重要原則

**パートナーが「勝手に紹介したくなる」設計**
- 創新ラボに任せると自分がかっこよく見える（提案品質が上がる）
- 面倒なことから解放される（バックエンド・契約・保守）
- 自分の単価が上がる（フロントだけ受けて上流を押さえられる）

**摩擦ゼロの発注体験**
- Slackで相談できる
- 1営業日以内に概算が出る
- 契約テンプレートを用意して手続きを最小化

## PartnerOps（運営体制）

単なるサポート窓口ではなく、パートナーが成果を出せる状態を維持・管理する機能。

**主な機能**
- オンボーディング（登録〜初案件獲得まで）
- 案件マッチング（スキルと案件の最適割当）
- 進捗管理・トラブル対応
- パートナーのパフォーマンス把握・改善

**体制**：統括1名 + PartnerOpsチーム複数名

**審査基準（クローズド型）**

| 審査項目 | 確認ポイント |
|----------|-------------|
| ポートフォリオ | 実際の納品実績（KASOU掲載作品で可視化） |
| 専門性 | フロント・デザインのどちらが強いか |
| コミュニケーション | レスポンス速度・誠実さ（面談で確認） |
| 規模感・稼働余力 | 個人 or 法人、現在の稼働状況 |

## 展開フェーズ

| フェーズ | タイミング | 施策 | 目標 |
|----------|-----------|------|------|
| Phase 0 | 今すぐ | KASOU掲載者からフロントメインの受託者を5〜10人ピックアップ → 個別に声かけ | クローズドパートナー5人獲得 |
| Phase 1 | 仕組み化 | Slack / NotionでPartnerOps向け案件相談・発注フローを整備 | 案件フロー自動化 |
| Phase 2 | エコシステム化 | KASOUにパートナー登録ページを設置 → 掲載者が自分で申請 | パートナー数スケール |
