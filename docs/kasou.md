## 概要・特徴

Webデザインギャラリー・リンク集。競合他社ギャラリーとの最大の差別化ポイントは**トップページだけでなく下層ページのデザインまで閲覧できる**こと。

全投稿が創新ラボの現役Webデザイナーによって更新されており、各デザインに**デザイナーのコメント**が付く。毎日更新。

## コンテンツ構成（3本柱）

### 1. 探す（ギャラリー）
- Webサイト・LPのデザイン事例を掲載
- 配色・カテゴリ・スタイルで絞り込み可能（フラットデザイン / リッチデザインなど）
- 掲載数は1,200件超（2026年6月時点でNo.1233まで確認）
- **掲載依頼を受け付けている**（外部サイトも掲載可能）

### 2. 知る（ナレッジ）
- Webデザインに関する記事コンテンツ
- 最近の記事例：「生成AIでLP制作してわかった10の失敗例」「AIでホームページ・LPを作る方法」「AEO入門」など
- AIやトレンド技術を積極的に取り上げている傾向

### 3. 学ぶ（スクール）
- 動画コンテンツによるWebデザイン・コーディング学習
- 未経験〜中級者向け
- 一部コンテンツは無料公開、一部は会員限定
- カリキュラム：Webデザインの基本 → Figma → コーディング（HTML/CSS/Sass/jQuery）→ WordPress → サイト公開

**学習カテゴリ一覧（15カテゴリ）**  
Webデザインの基本 / Figmaの使い方 / Figmaで実践 / Webデザインの作り方 / デザイン制作課題 / コーディング環境の準備 / HTMLの基本 / CSSの基本 / パーツのコーディング / コーディング実践 / Sassコーディング / jQuery / WordPress / ドメインの取得 / サーバー

### 4. 依頼する（リード獲得）
- サイト無料診断のCTAが設置されている
- 問い合わせ先は創新ラボ

## プロダクト方向性（2026-06-25 議論）

### コンセプトの絞り込み
「Webページ参考を保存・整理できる場所」に特化する方針。記事・スクールは優先度を下げ、ギャラリー（探す・保存する）をコアに据える。

Pinterestとの差別化は**下層ページまで見れる**という情報の深さ。これはKASOUにしか作れない体験。

### マイコレクション機能の構想
現在の保存ボタンはブラウザローカル保存（ユーザーデータがKASOUに蓄積されない）。

**目指す体験**
1. 保存ボタンを押す → ブラウザ保存 + 「マイコレクション作れるよ」モーダル表示
2. メアド登録 → アカウント作成
3. ログイン後はフォルダ分けしてコレクション管理できる

**メリット**
- メールリストが資産になる（今はユーザーが見えない状態）
- 登録動機が「自分のコレクションを整理したい」という自然な欲求 → 摩擦が少ない
- ログインユーザー = デザイン系に関心が高い層 → パートナー候補・クライアント候補として活用できる

**実装の優先順位（案）**
- Phase 1: メアド登録だけ先に作る（保存時のモーダル → 登録）
- Phase 2: コレクション・フォルダ管理機能を追加
→ 登録してもらう仕組みを先に、体験は後

### ナビゲーション・構造の見直し

**現状**: 「探す・知る・学ぶ」が横並びで等しく扱われている → ギャラリー特化のコンセプトと矛盾

**方針**:
- ファーストビューはギャラリーのみ。来たらすぐ探せる体験
- 記事・スクールはgnavに置くだけ（存在はするが主役ではない）
- 記事は「裏で流入を稼ぐ装置」、ギャラリーは「表の体験」という役割分担
- SEOの恩恵は同一ドメインの別ディレクトリ（`/knowledge`など）に置く限り維持される

### 記事・スクールの位置づけ見直し
- ナレッジ記事: SEO流入源として維持するが、UIでは前面に出さない。ギャラリーからの動線（記事内に関連ギャラリーを埋め込む）を整備して回遊を促す
- スクール: 一般公開の優先度を下げ、パートナー向けクローズドコンテンツとして転用する方向

## KASOUの強み：2つのターゲットが同じ体験に集まる

「デザインを探して保存する」という単一の体験が、2種類のユーザーの自然な入口になっている。

| ユーザー | KASOUの使い方 | 次の動線 |
|----------|-------------|---------|
| クリエイター（デザイナー・FE） | 参考デザインを集めたい | パートナープログラムへ |
| 企業担当者 | こういうサイトを作りたいという参考を探したい | 「依頼する」CTAへ |

同じギャラリー体験が2つのファネルの入口を兼ねているため、メディアとして効率が高い。

**将来的な拡張**：マイコレクションを発注の参考としてそのまま共有できる機能があると、企業側のクライアントファネルとしてさらに強くなる。

## ELGにおけるKASOUの位置づけ

KASOUはELGパートナープログラムの**起点となるコミュニティ資産**。

- **掲載者 = パートナー候補**：KASOUにサイトを掲載しているデザイナー・フロントエンジニアは、実績が可視化されているためパートナー審査の起点として活用できる
- **ユーザー = 潜在クライアント**：Webデザインに悩む企業・デザイナーが集まるため、そのまま案件創出につながる
- **スクール = パートナー育成**：学習コンテンツを通じてスキルアップをサポートし、将来的なパートナー候補の育成にもなる
