## 2つのファネル

KASOUのギャラリーが共通の入口。そこから「パートナー」と「クライアント」に分岐する。

### ① パートナー獲得ファネル（ELG）

デザイナー・フロントエンジニアを創新ラボのパートナーにする流れ。

| ステージ | 内容 |
|----------|------|
| AWARENESS | KASOUにサイトを掲載 → コミュニティに参加 |
| INTEREST | パートナー紹介ページを見て「創新ラボと組むと稼げる」を認知 |
| ACTION | パートナー登録申請 → 審査 → Slack招待 → オンボーディング |
| ACTIVATION | 初案件の紹介 / 協業（紹介型 or 協業型） |
| EXPANSION | 口コミ・紹介連鎖 → パートナーがパートナーを呼ぶエコシステムへ |

### ② クライアント獲得ファネル

制作会社を探す企業・担当者が問い合わせるまでの流れ。

| ステージ | 内容 |
|----------|------|
| AWARENESS | KASOUギャラリー閲覧（デザイン参考・制作会社探し） |
| INTEREST | ナレッジ記事・実績閲覧 → 「依頼できそう」という信頼形成 |
| ACTION | 無料診断 / 問い合わせ（KASOUのCTA or コーポレートサイトから） |
| ACTIVATION | 商談 → 受注 |
| EXPANSION | 継続・追加受注 + 紹介による新規獲得 |

## 現状のギャップ（作る必要があるもの）

### パートナーファネルで不足しているもの

**1. パートナー登録ページ（KASOU内）**
- 「パートナーになるとどんなメリットがあるか」を伝えるランディングページ
- 申請フォームへの導線

**2. オンボーディング素材**
- サービス説明資料（創新ラボが何をどこまでやれるか）
- 料金・単価の目安 / 協業型の按分ルール
- 提案トーク集（クライアントへの説明の仕方）
- 発注フロー（相談→概算→契約の流れ）
- 事例・実績集

**3. パートナー向けe-ラーニング（KASOUスクール基盤を活用）**
- クローズド動画コース（パートナー登録者限定）
- 3〜5本程度で十分
- コンテンツ案：
  - 創新ラボのサービス概要（できること・できないこと）
  - 案件の見極め方（受けていい案件の範囲）
  - クライアントへの提案の仕方
  - 発注・連絡フロー（Slackの使い方）
- 制作順序：サービス説明資料が固まってから動画化

### クライアントファネルで不足しているもの

- コーポレートサイトの実績・信頼コンテンツの充実
- KASOUからコーポレートサイトへの導線強化

## コンテンツマーケティング（記事トラック）

インバウンドの長期的な主力。ただし**2トラック必要**で、それぞれ対象が異なる。

| トラック | 媒体 | 対象読者 | 効くファネル | 現状 |
|----------|------|----------|------------|------|
| デザイナー向け | **KASOUナレッジ** | デザイナー・フロントエンジニア | パートナー獲得 | あり（継続強化） |
| 発注企業向け | **コーポレートサイトのブログ** | 開発を外注したい企業担当者 | クライアント獲得 | なし（要着手） |

**役割分担の原則**: KASOUはデザイナーコミュニティ、コーポレートサイトは企業向け、と明確に分ける。KASOUに企業向け記事を混在させるとブランドポジションが崩れるため、対象読者は徹底して分離する。

コーポレートブログの想定キーワード例：「システム開発 費用相場」「アプリ開発 外注 選び方」「DX推進 事例」など。実績ページ完成後に着手するのが現実的。
